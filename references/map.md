# 给人的地图：说需求，也可以直接放资料

[English](map.en.md)

这是包内的使用说明。启用后的个人工作区根目录有 `MAP.md`，它连接你的实际材料、事项和机会；Agent 的导航是旁边的 `AGENT-MAP.md`。两张地图由同一份清单生成，你不必分别登记。

## 我有什么、放在哪里

| 你手里的内容 | 直接放入工作区 | Agent 整理后留在哪里 |
| --- | --- | --- |
| 简历、证书、过往工作/项目材料、旧笔记 | `past/materials/`，可自建子目录 | `past/` 的个人、工作、教育、项目、学习等独立记录 |
| 正在做的项目、当前学习资料 | `present/materials/`，或 `present/items/<事项>/materials/` | 同一事项摘要、行动、学习/工作进展 |
| 还没确定方向的公开资料、JD | `future/materials/` | 确定需要留存时再建立或关联方向 |
| 某方向或公司的 JD、招聘截图、反馈 | 对应方向/机会的 `materials/` | 该方向、公司机会的 JD、判断和反馈 |
| 暂时不知道放哪 | `inbox/` | Agent 处理相关问题时再帮你分类 |

保留你放入的原件和文件名；普通笔记、PDF或Word不需要填写内部字段。资料放入不代表已被读懂，整理结果也不自动成为确认事实。简历照片由Agent按照片流程处理。

## 说一句就能开始

| 你现在的问题 | 会发生什么 |
| --- | --- |
| 我刚放了新简历，结合我的经历分析一下 | 检查相关入口，读新简历，核对已有记录，先给结果或整理草稿 |
| 我最近想换方向，还没想好 | 先讨论；不必马上建目标、填公司或排日程 |
| 继续上次的作品 | 找回该事项已保存的目标、停点、未定问题与下一步 |
| 今天/这周做什么 | 查看同一套已有行动；不会顺手重排 |
| 这份作品说明改到周五 | 展示这一项的日期差异与直接影响，确认后保存 |
| 准备星桥这场面试 | 定位该机会资料、上次准备和相关经历成果，继续准备或逐题练习 |
| 看一下各公司进展 | 从已保存事件生成全局或单岗视图 |
| 先保存这个想法，不建项目 | 给独立note草稿，放present/notes，不强制关联目标 |
| 我想回看这段工作，再想想下一步 | 从实际事项/成果形成阶段摘要，不自动结束或重排事项 |

小问题留在对话里解决。需要比较、计划或查看整体时，再让Agent展示视图。日常无需先到网页复制一段指令。

## 在地图里看整理到哪了

`MAP.md` 与分区清单显示材料路径、名称、状态和检查范围。待整理、已关联整理记录、已更新待复核、缺失分别标识；未检查区域保留原时间。没有后台监听，Agent进入相关部分时才检查变化。

事项是长期主线，多段小对话围绕它继续。值得保留的结论由Agent合并成具体摘要，你确认后保存；只说过但没保存的内容，不当作长期记忆。

你可以直接编辑正式 Markdown 的正文，下次Agent以实际文件为准。改任务日期或状态时，要改对应的 `scheduled_for`、`due_on`、`status` 字段；只改正文日期不会重排日程。可以直接让Agent代改，不需要记字段；手动改时保留ID、合法JSON值和已有历史。若文件格式被改坏，它应指出具体问题。

中文工作区先打开“从这里开始.md”，英文工作区打开START-HERE.md，再沿MAP查真实路径。若移动了Skill包，让Agent修复本地定位，原资料不重建。已完成、暂停的事项、独立想法与阶段回看可以在总览内展开。详细目录、语言与定位修复见 [navigation.md](navigation.md)，Agent如何读见 [agent-map.md](agent-map.md)。
