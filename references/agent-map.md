# 给 Agent 的读取地图

[English](agent-map.en.md)

这是包内路由；工作区的 `AGENT-MAP.md` 与 `navigation/` 清单给出该用户的实际路径和检查范围。先固定工作区，验证身份；本对话已经读过且未变化的规则不用重复加载。无关问题不强制进入履迹。

## 三层读取

1. **总导航**：工作区 `AGENT-MAP.md` 确定区域。没有地图时按 [navigation.md](navigation.md) 为已有 MD 工作区刷新；不重新初始化或迁移旧格式。
2. **区域清单**：只检查本次相关范围，使用 `md_navigation.py refresh --scope ...`，再按名称、类型、事项/岗位/公司标识选对象。`catalog` 只读上次清单；未检查不是空库。
3. **对象与来源**：先读选中的事项/目标/机会摘要，再显式读取本轮必要的正文与引用。需要保存时用 `md_workspace.py context` 取得实际来源闭包和版本，导航缓存不能代替它。

| 用户当前问题 | 相关范围与先读对象 | 再按需读取 | 进入工作流 |
| --- | --- | --- | --- |
| 新放了简历/学习材料 | `past/materials/` 或用户指定入口；必要时 `inbox/` | 新原件、可能重复的相关记录 | [past.md](past.md) |
| 继续某个作品/探索 | `present/items/` 清单中该事项 | 摘要中的停点、相关行动、最新日志与本事项材料 | [present.md](present.md) |
| 今天/这周有什么 | `present` 中相应 period 计划元信息 | 计划引用的行动及必要依赖 | [present.md](present.md)；查看不重排 |
| 想换方向/比较岗位 | `future` 中对应方向清单 | 目标、选定 JD、与问题有关的经历/确认产出 | [future.md](future.md) |
| 准备某家公司面试 | 方向清单 → 该公司机会目录 | 该轮停点、JD、相关故事与底层事实/产出 | [interview.md](interview.md) |
| 根据材料制作简历 | 所选方向/机会与 `past` 相关入口 | 必要身份、学历、工作/项目与确认成果 | [resume.md](resume.md) |
| 查看进展或某份材料 | 当前范围的已有正式记录 | 实际路径及所需来源；不为查看建目标 | [views.md](views.md) |
| 只保存想法、不建事项或方向 | 本轮讨论；必要时已有note | 实际选用的引用；不强制链接 | [present.md](present.md) |
| 回看阶段/离职/Offer/入职/转向 | 所选时间范围的事项与已有阶段摘要 | 真实日志、产出、反馈；必要时当时的目标 | [stages.md](stages.md) |

范围不明时先靠清单定位；同名事项/多家公司会影响结果时，给少量明确选项。预算未知不阻断讨论，但不擅自落具体日程。通用面试讨论不要求先建方向，公司版正式归档再确认必要范围。

自然语言引导按[逐轮协议](turn-protocol.md)的“自然语言触发与适时引导”：缺资料不阻塞开始，探索不自动建方向，具体草稿合并一次确认。用户只说想开始、尚无工作区时先讨论，不为查“过去是否为空”而初始化或扫描私人目录；已有工作区也只核对本轮相关范围，未检查区域不下空库结论。

## 两条输入路径共用一次整理

- **对话给资料**：按用户指定范围读取；明确要求留存原件时可用原导入流程，事实草稿另确认。
- **直接放文件**：按范围检查目录发现新材料；保留原名原位，普通 MD 不要求 frontmatter。使用宿主读取实际内容，不能因文件名/哈希推断正文。新原件可以先支持只读分析，正式经历/目标/日程仍先给具体草稿。

确认保存后回读正式记录；对已整理原件用导航 `link` 核实关联，再刷新相关地图。`processed` 只说明有符合版本条件的整理记录，不证明每句事实正确。新版本或缺失文件要指出具体影响，不自动改旧结论。

## 续接同一件事

工作区入口会记录本地Skill位置；先验证候选，移动或缺失时按[navigation.md](navigation.md)显式setup修复，不扫描私人目录猜位置。语言仅影响指南与地图，不变更职业记录身份或路径。

事项是长期对象，小对话是过程。只从已保存摘要恢复：目标、已决定、未确定、当前停点、下一步、引用来源、待采纳草稿及记录日期。不默认读取其他事项或宿主全部聊天；未保存内容不能冒称记忆。用户明确切换对象时改变本轮焦点，不把浏览选择当职业目标采纳。

人的使用入口见 [map.md](map.md)，文件与命令见 [workspace.md](workspace.md)。
