# 用虚构资料试一遍

本目录人物、学校、公司、岗位和产出全部虚构，不能当成真实用户资料。两种测试回答不同问题。

## 自然对话试用

让一个没有前文的新Agent读取本包AGENTS与SKILL，再只给它以下话术和本目录resume.md、learning-plan.md：

> 在一个新的临时目录里试用履迹。这是我的旧简历和学习计划，帮我整理过去。先给我具体草稿。我想探索AI产品方向，但还没决定。本周只有五小时，想知道下一步怎么做。不要读我的真实资料，不要联网，不要投递。

它应先保留指定原件、区分旧计划与已完成内容，展示事实草稿再等待确认；不能自动排旧任务。后续选择：

1. 看草稿后说“保存这版”。检查工作、教育、项目、学习是否各自有可读MD。
2. 给两份虚构JD，让它分析差距，形成目标/公司档案和周计划草稿。确认后看周视图。
3. 只把一个行动改期，检查月视图引用同一行动，其他任务没有被重排。
4. 给evaluation-notes.md说明这是产出，检查它没有仅因done就升为能力；证据确认另行说明。
5. 要求制作网页简历，检查事实/来源和分区；看过HTML后再明确要求PDF。
6. 报告某公司的反馈，检查事件历史和单岗/全局视图一致。
7. 说“下周五要面试星桥，只有45分钟，结合项目和最近学习帮我准备，再练一个追问，不改原学习计划”。检查岗位故事与公司轮次稿能找到来源，回答后才记录模拟摘要；保存后另一轮能续接，没有新增虚构工作成果、改变投递阶段或自动排程。

这一步评估Agent是否会用Skill；不把自动化里的模拟确认当真人确认。

## 没有历史资料时的引导试用

以下各情境使用虚构身份，除续接步骤外互相独立。先只提供用户话术，让Agent实际回应，再检查结果；不要把验收答案当用户上下文。没有确认保存时，不应产生正式职业文件。中英文表达应走同一语义规则，不以中文关键词匹配代替理解。

| 用户话术 | 应观察的行为 |
| --- | --- |
| 我没有旧简历，暂时也不补资料。我想试试产品经理，这周有三小时，先帮我拆一个月的推进思路，不用保存 | 直接给起步草稿，相关基础保留未知；不要求先补学历/简历，不建正式目标或日程 |
| 接上条：先不补资料，你继续拆第一周；我暂时只想做项目 | 不重复提醒上传；项目可独立于未来，计划不超过已给容量，不声称已保存 |
| 我想了解产品经理，但还没决定；以前想过做设计师，现在不考虑了 | 探索当前问题，不把历史/否定愿望建为目标，也不强制建当前方向 |
| 我决定往产品经理发展，帮我在未来记录下来，具体公司还不知道 | 展示初步方向草稿与位置，已有方向则更新；无需JD/公司先齐全。看到草稿后另给模拟确认，才能保存 |
| I want to explore product management. I have no resume to upload yet. Let's just discuss what I can try this week. | 英文回应，先探索可尝试行动；不要求简历、不自动采纳方向或保存 |
| 我还不知道每周有多少时间，但想做一个半年的作品项目 | 可以拆阶段成果，具体排期/容量待定；项目仍可留此刻，不因半年就强制归未来 |

另测已有方向重复提及、只保存当前项目、不保存方向，以及“继续”与对确切草稿的保存确认。跨对话延续“暂时不补”的选择时，先展示并模拟确认包含该选择的事项摘要，让新Agent只用已存摘要继续；没有摘要时应说明缺失，不虚构记忆。定时通知不在这些对话内提示测试中。

## 直接放资料与换对话的三条试用路径

使用同一个隔离虚构工作区，由测试者直接放文件；以下是验收步骤，不是已经通过的声明。用户仍不需要运行命令或填写内部字段。

**新简历。** 先让Agent初始化新空库，打开工作区 `MAP.md`，检查能找到资料入口和分区检查时间。把本目录 `resume.md` 原样放到 `past/materials/resume/旧简历.md`，不加frontmatter，然后说：

> 我已经把旧简历放进文件夹，结合它分析一下我有哪些积累。先别改我的正式经历。

Agent应沿清单发现新材料、按需读正文；只读分析不要求保存确认。随后让它给具体事实草稿，再说“保存这版”。检查原件字节/名字/位置不变，正式MD引用原路径与实际版本，整理关联核实后人/Agent地图状态一致。不能因发现简历就自动采纳旧学习计划。

**公司JD。** 在已有虚构方向/公司机会的 `materials/` 下放 `jd-starbridge.md`，再说：

> 帮我准备星桥这份岗位的面试，先看新放的JD，别读其他公司的材料。

Agent应只检查并读取该范围的新JD、已有准备摘要与相关经历成果，不要求复制页面指令。新JD仍是原件，正式JD需要草稿/确认后才更新；准备不改变投递阶段或原计划。另一公司正文、无关照片/联系方式应保持未读。没有方向档案时可先通用讨论，不为保存要求立即建整套公司结构。

**换对话续接。** 在前一对话让Agent给一份事项续接摘要，包含目标、已定/未定、停点、下一步、来源和待采纳草稿，明确确认保存。然后让一个没有前文的Agent只拿包位置与同一工作区，提出：

> 使用履迹，继续上次的检索评估作品。

检查它先看地图/事项清单，再读对应摘要与必要来源；能指出仍未采纳的建议，不假称知道上次全部聊天、不扩大读取其他事项。若尚未保存摘要，应诚实说明缺失，而非猜测停点。

三条路径另测：修改已关联原件后只刷新相关范围，显示待复核；删除原件显示缺失；未检查区域保留旧时间；目录读取失败保留旧地图并报错。额外把普通学习材料命名为 `past/materials/学习资料/README.md`，检查它作为原件被发现。仅固定位置、已识别的生成指南不列作材料，不要求用户为避开工具而改文件名。

## 独立想法、阶段回看与移动后续接

在隔离库说“先保存这个想法，不建目标、不排期”，检查Agent先给具体note草稿，模拟确认后只有独立记录。接着回看这段经历，检查stage-summary引用实际来源，既有记录字节与状态未变，没有自动建下一轮行动。新进程只给工作区路径，检查它能由入口定位Skill，按清单恢复相应note或阶段摘要，不读遍全库。

另在包外建立英文工作区，使用 `init --language en`。让英文用户检查START-HERE、MAP、分区说明中的投放路径、日期/状态字段与人/Agent职责；无过去资料也能探索，未知周容量不虚构日期。移动测试包后按[navigation.md](../references/navigation.md)显式setup重新连接，核对manifest、职业记录ID/字节不变。目录移动、确认和重连均由测试者明确标注为虚构演练，不代表真人或所有宿主验收。

## 确定性离线演示

维护者或Agent执行（用户不用运行）：

```text
python3 scripts/demo.py --workspace <一个全新且不存在的临时目录> --date 2026-10-23
```

工具拒绝现有目录，不读取LUJI_WORKSPACE_DIR。固定虚构输入→原件导入→细分MD→一个主要方向/两个公司及一个未评估备选→五小时周行动→虚构产出确认→新版判断→通用/公司HTML→模拟反馈节点→岗位故事/公司准备/模拟记录/改进新版→离线快照。面试环节不额外改变阶段或行动。所有确认均明确为演示模拟，不联网、不发送、不生成PDF。

示例默认带AI生成虚构头像A；可加 `--avatar b` 使用另一张虚构头像，或 `--avatar none` 完全无头像。两份岗位/公司示例使用同一选定头像，图片仅为演示素材，不是身份或经历事实。

想先比较样式，由Agent执行 `python3 scripts/demo_gallery.py --output <新的预览目录> --date 2026-10-27`。生成index.html、六排版×A/B/无图共18个预览，以及7个GitHub参考外链。选排版或头像只改变预览，不代表已保存正式用户简历。三种头像分别使用独立虚构库，不混用照片来源；生成输出不装进公开Skill。

运行时草稿/历史留在临时工作区，不装进公开Skill。可打开输出HTML查看，也可删临时目录重跑。演示是协议和视图验证，不代表Agent自动理解附件、真人授权或所有宿主展示已验证。
